# MVP Saúde Básica

Sistema simples para monitoramento de pacientes (gestantes e crianças).

## Funcionalidades
- Cadastro de pacientes
- Identificação de pendências
- Visualização em lista

## Como executar
1. Baixe os arquivos
2. Abra o arquivo `index.html` no navegador

## Objetivo
Validar a ideia de uso de dados na saúde básica.
